## Open questions resolved by the implementer (recorded here so the plan is self-contained)

1. **"Catholic Undergraduate Students' Society" (§4) vs "Catholic Undergraduate Teachers'
   Society" (§10).** The Teachers' form is used, because §10 states it twice and the Facebook
   page name in §8 confirms it.
2. **"Bulettin" (§3)** is a typo for "Bulletin". The button reuses the existing
   `nav.bulletin` string ("Bulletin" / "Buletin").
3. **"Tanjong Malim" (§8) vs "Tanjung Malim" (§4, §10).** The postal address block is copied
   verbatim from §8 ("Tanjong Malim"); running prose keeps "Tanjung Malim".
4. **"banner/testimonial block" (§7)** is read as covering both the dark "THERE'S A PLACE FOR
   YOU HERE" call-to-action *and* the "REAL STORIES. REAL PEOPLE." testimonial above it. The
   testimonial quotes a named person ("Grace Tan") who was invented as placeholder copy, so it
   must not ship regardless.
5. **Logo explanation language (§10).** The Bahasa Malaysia page carries the four lines exactly
   as written above; the English page carries an English translation of them.
6. **Council photos (§6).** The Google Drive folder cannot be fetched by the build. Each council
   member gets an optional `photo` path, empty until the committee drops files into
   `Website/public/council/`. An initials monogram renders in the meantime.
7. **Facebook URL (§8).** Only the page *name* was given, not a URL. Facebook renders as plain
   text until someone supplies the link; Instagram and TikTok render as links.
